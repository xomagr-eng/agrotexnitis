# 🌿 Αγροτεχνίτης ΤΝ

Έξυπνη γεωργική διαχείριση με ΤΝ — αγροτεμάχια & δέντρα, ημερολόγιο εργασιών, φαινολογία & πρόβλεψη απόδοσης, φυτοπροστασία & άρδευση, αυτόματο πρόγραμμα ψεκασμών/λίπανσης/άρδευσης, χάρτης με σχεδίαση ορίων. Έμφαση στην ελιά και σε όλα τα δέντρα/κηπευτικά της Ελλάδας.

- **Offline-first PWA** — εγκαθίσταται στην αρχική οθόνη του κινητού.
- **Καιρός:** Open-Meteo (δωρεάν, χωρίς κλειδί).
- **Χάρτης:** Leaflet + OpenStreetMap.
- **Δεδομένα:** αποθηκεύονται τοπικά στη συσκευή (localStorage) — δεν φεύγουν πουθενά.

Άνοιξε το `index.html` σε browser ή δες το online μέσω GitHub Pages.
